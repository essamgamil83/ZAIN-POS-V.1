# Zain ERP V1.0 2026

This is the main repository for the Zain ERP project.

## Project Structure

-   `backend/`: Contains the Django backend code. See the [backend README](./backend/README.md) for more details.
-   `frontend/`: Contains the React frontend code. See the [frontend README](./frontend/README.md) for more details.

## Getting Started

To get started with the project, you need to set up both the backend and the frontend. Please refer to the README files in each directory for specific instructions.
